Designing a calmer way to manage money.

VELIX focuses on the everyday banking actions people need most, while reducing the visual and cognitive friction found in feature-heavy financial apps.

03 / PROBLEM

Banking shouldn't feel like navigating a control panel.

Many banking applications contain numerous financial services that overwhelm users and make common actions slower than necessary.

VELIX was designed to reduce interface complexity and prioritize essential tasks such as checking balances, transferring money and managing transactions.

01

05 / CORE FEATURES
User Authentication Secure Login PIN Verification Dashboard Money Transfer Transaction History Card Management Notifications Profile Management Payment Confirmation
06 / COMPETITIVE LANDSCAPE

Learning from familiar financial products.

I analyzed Google Pay, PhonePe, Paytm, Revolut and Monzo with a focus on navigation patterns, dashboard layouts, transaction workflows and visual consistency.

Google Pay Simple onboarding · Fast QR payments
PhonePe Strong UPI · Feature-rich navigation
Paytm Comprehensive · Information-heavy
Revolut Premium UI · Budgeting
Monzo Minimal · Clear history
07 / DESIGN DECISIONS
01

Balance first

Account balance became the primary dashboard anchor.

02

Less noise

Secondary information was reduced.

03

Primary actions

Transfer and Scan QR receive clear priority.

04

Readable dark UI

A controlled dark theme supports hierarchy.

08 / TARGET USERS
PRIMARY USERS
  • Working professionals
  • College students
  • Small business owners
USER GOALS
  • Check balance quickly
  • Transfer money securely
  • Pay bills efficiently
  • Monitor transactions
  • Manage cards
PAIN POINTS
  • Cluttered interfaces
  • Unnecessary features
  • Complex navigation
  • Unclear financial overview
